Discord Live Notifier Setup

Follow these steps to configure your automated Twitch-to-Discord stream alerts.

What You Are Building

Once set up, Streamer.bot will automatically post a dynamic live notification when your broadcast begins, and it will seamlessly update to a summary wrap-up when your broadcast ends.

Phase 1

Create a Discord Webhook

  • Click your Discord server name at the top left to open the dropdown menu.
  • Select Server Settings.
  • Navigate to Integrations on the left sidebar.
  • Click on Webhooks or "Create Webhook".
  • Change the name, add a picture, select the channel where you want your live alerts to appear, then click Copy Webhook URL. Save this link for later.
Phase 2

Get Your Custom Role ID (Optional)

  • While still in Server Settings, navigate to the Roles tab.
  • Find the specific role you want the bot to ping when you go live.
  • Click the three dots (...) next to the role and select Copy Role ID. Save this number for later. But if you don't want any role, it will mention @everyone
Phase 3

Get Your Twitch Profile Logo

  • Go to your Twitch channel and click your profile picture icon in the top right corner.
  • Right-click the larger profile image that appears and select Copy image address. Save this link for later.
Phase 4

Configure Streamer.bot Variables

  • Open Streamer.bot, navigate to the Actions tab, and select the imported Twitch Notification action.
  • In the Sub-Actions window, locate and expand the green Setup folder.
  • Double-click each Set argument line to paste the information you gathered in the previous steps.
